# Side projects

One folder per project. Copy `_project-template/` to start a new one.

| Project | Idea | Status |
|---------|------|--------|
| `premiummchub` | Catalog of Minecraft clients, mods and macros with a public storefront and a password-protected admin panel (React, Vite, Vercel) | done |
| `py-bank` | Command-line bank system: register and log in, accounts, transfers, SQLite storage, tests | done |
| `ai-knowledge-assistant` | Personal RAG assistant: upload text/PDF documents, ask questions and get answers with sources (Flask, React, Ollama, Docker) | done |
| `expense-tracker` | Command-line expense tracker: add, list, delete, filter, summarize and export spending to CSV | done |
